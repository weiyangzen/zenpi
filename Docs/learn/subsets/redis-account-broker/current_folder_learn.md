# Redis Service Subset

The selected files connect readiness, buffers and persistence. I/O helpers can
exist while one owner validates each state transition. A readable socket, parsed
request, accepted mutation, durable record and delivered reply are different
milestones. Broker accounts/connections have one owner; paid requests require a
durability barrier. Slow storage and slow readers apply bounded backpressure
without blocking control input. These notes are evidence, not another checklist.
