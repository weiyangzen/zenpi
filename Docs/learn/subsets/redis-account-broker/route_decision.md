# Route And Target Contract

Mode: understand; route: high-reasoning, direct root review; no worker or cron.
Scope: frozen source windows in three files, not a whole-file/repository audit.
The manifest owns coverage. No upstream code is copied or installed.

One note per selected source file mirrors the source tree. Root and src folder
synthesis have separate coverage indices. Out-of-scope: replication, cluster,
Lua, general database commands, modules and background rewrite workers.

Acceptance: identify state ownership, input/output, failure, executable local
rules and counterexample tests. Product contracts state the rules directly,
not instructions to consult external code. This isolated learning root does not
overwrite the repository's existing learning campaign. No cron is created.
