## Complete declaration contract

Image APIs/providers have their own aliases. ProviderStreams supplies stream/simple operations and optional deferred fetch/cancel; ProviderImages returns an image-generation promise. Deferred cancellation is best effort, not confirmation of remote completion.
2. Reasoning and tool choice: ToolChoice has auto/none. ThinkingLevel includes minimal/low/medium/high/xhigh/max; ModelThinkingLevel additionally allows off. Partial model level maps distinguish absent keys/default behavior from null/unsupported; budgets cover minimal through high. Chat template variables and omit-if-off declarations are configuration contracts. None of them alone executes validation or model configuration.
3. Request options: optional signal, authentication, telemetry, fetch, provider environment, headers, payload and response callbacks are distinct. The onPayload undefined result preserves the existing payload; custom fetch is not a WebSocket transport hook. Comments define provider-env precedence, null-header suppression and Bedrock reserved-header exceptions. They do not enforce these rules at runtime here.
4. Timeout/retries/transport: client retries, timeouts and maximum server-requested delay are separate fields. Comments about a 60000 ms cap and zero disabling it do not implement scheduling, idempotency or retry policy. SSE/WebSocket/cached/auto choices, WebSocket handshake and idle limits, cache retention, session affinity and metadata are independent. Sampling key precedence is described for the relevant OpenAI-compatible path, not universally implemented by the type system. ApiOptionsMap selects known concrete options with a generic fallback for custom APIs.
5. Stream setup/error semantics: StreamFunction comments permit missing-auth failure before a stream is returned; subsequent failures use stream events. 6. Content blocks: text signatures accept a legacy ID or a serialized versioned signature with phase. 7. Usage: input/output/cacheRead/cacheWrite/total and cost fields are distinct. Reasoning tokens are a subset of output; cacheWrite1h is a subset of cacheWrite.
