# MBTI coding/work persona integration

Zenpi keeps all sixteen selectable MBTI labels and presents them as four
practical coding-agent families and the referenced agent frontmatter colors:
Analysts (NT, purple), Diplomats (NF, green), Sentinels (SJ, blue), and
Explorers (SP, yellow). Their profiles cover
architecture and tradeoffs; collaboration and user impact; reliable delivery
and tests; and pragmatic experimentation and debugging, respectively.

This is a communication preference only. It never changes permissions,
approval posture, model selection, factual standards, or task requirements.
